# ctp-gui 可执行文件（交付说明）

生成时间：2026-11-04
源码版本：工作区 `D:\pay2`（Rust 1.99，edition 2021，SQLite 以 bundled 方式静态编入）

## 一、文件清单

| 文件 | 大小 | 说明 |
|---|---|---|
| `ctp-gui.exe` | 17.1 MB | **图形界面版**，双击即用，含中文字体与全部本期功能 |
| `data\ctp.db` | 184 KB | 界面默认使用的数据库（exe 同级 `data` 目录），已含演示数据 |
| `demo.db` | 184 KB | 同一份演示库的副本，可拷成 `data\ctp.db` 覆盖，恢复到初始演示状态 |

单一二进制，`cargo build --release` 构建；Windows 版用本机 MinGW-w64 gcc 16.1 作为 `cc` 链接 SQLite。
无需安装任何运行时，也没有 WebView / 前端框架依赖。

## 二、使用说明

双击 `ctp-gui.exe` 即可。首次启动若 `data\ctp.db` 不存在，会自动建库并写入基础字典。

**六个页面**（左侧导航切换）：

| 页面 | 内容 |
|---|---|
| 总览 | 6 项关键指标、最近拨款、会计分类占比，「载入演示数据」入口 |
| 合同台账 | 搜索 / 状态筛选、合同明细、右侧详情卡（附件、登记审计价、修改金额、去拨款、作废） |
| 拨款管理 | 选择合同 → 四张额度卡（基准 / 已付 / 可付额度 / 单据数）+ 登记表单 + 拨款明细；每行「打印」可预览付款打印数据 |
| 分类汇总 | 按会计分类的 V3 汇总，含合计行与支付进度；右上角「导出 Excel」 |
| 期间统计 | 按月份的 V4 柱状图 + 明细表，含占比列；右上角「导出 Excel」 |
| 自检与设置 | 六项口径自检、超付容差设置、数据源路径 |

**交互细节**：

- 窗口可自由缩放，最小 1000×640；宽度小于 1100 时左侧导航自动折叠为两字缩写，悬停显示全名；
- 右上「切换深色 / 切换浅色」在浅色与深色两套配色间切换，立即生效；
- 按钮有常态 / 悬停 / 按下 / 禁用四态；必填未填或金额非法时，提交按钮直接置灰，不用点了才报错；
- 弹窗打开时背景压暗，表单字段分两栏排布，小屏也不截断按钮；
- 新建合同分两步（基本信息 → 附件）；所属项目 / 承包单位 / 发包人都是带联想的输入框，
  输入库里没有的新名称会自动建档；
- 附件四类分项、每类一份，文件存进数据库，单份上限 50 MB；合同附件为必传项，卡点在「设为生效」；
- **报表导出**：分类汇总 / 期间统计两页的「导出 Excel」用 `rust_xlsxwriter` 生成单页 .xlsx，
  表头加粗、冻结前三行、金额 `#,##0.00`（单位元）、合计用 `SUM` 公式，并写一条 `EXPORT` 审计日志；
  屏幕表格与导出共用同一份 `ReportResult`，口径不会分叉；
- **付款打印预览**：拨款管理页选中一条付款单 → 「打印」，弹出 9 个 Word 合并域的取值与来源
  （含本次金额中文大写）。**本轮按确认结论不生成 docx 文件**，模板填充 adapter 待后期接入；
- 底部状态栏常驻提示（成功绿色、失败红色），右侧显示当前超付容差。

**排查用的环境变量**（一般用不到）：

```
set CTP_SCREEN=payments     启动直接进某个页面
set CTP_THEME=dark          启动即深色
set CTP_DIALOG=new_contract 启动即打开某个弹窗（另有 attachments / payment_detail / print_preview / audit_price / edit_amount / void_payment）
set CTP_STEP=1              与 new_contract 配合，直达第二步（附件）
set CTP_SELECT=1            启动即选中第一份合同（看详情卡）
set CTP_SELFTEST=1          跑满 40 帧后自动退出，并在 exe 同级写 smoke.txt
```

`CTP_SELFTEST` 是无界面验证手段：退出码 0 且 `smoke.txt` 里 `ok` + 数据条数正常，说明窗口与渲染管线都在正常工作，
适合在远程桌面或窗口被遮挡、截不到图的环境里快速确认程序本身没坏。

## 三、已验证

- WSL Debian：`cargo build --release` 与 `cargo test --workspace` 通过，69 项测试全绿（38 领域 + 4 存储 + 9 应用层 + 18 集成），0 警告；
- 图形界面：六个页面 + 各类弹窗（新建合同两步、附件管理、登记审计价、修改金额、作废确认、拨款详情、付款打印预览）逐屏截图核对，
  浅色 / 深色两套主题、全宽与 1040×700 窄窗均无控件裁切；
- 附件链路：上传 / 替换 / 另存 / 删除、每类唯一、空文件与超 50 MB 拒绝、生效前必传校验，均有集成测试覆盖；
- 报表链路：V3/V4 共用 `ReportResult`、xlsx 可打开（zip 头校验）、合计公式与 EXPORT 审计日志均有集成测试覆盖；
- 打印链路：9 个合并域逐项断言（含中文大写、未审定填 0、本次之前累计已付）、空实现返回明确的「未实现」；
- `CTP_SELFTEST` 冒烟验证 40 帧渲染正常、退出码 0，数据加载为 3 份合同 / 5 笔拨款；
- 回归：每次改动后 `cargo test --workspace` 与 `cargo build --release` 均为 0 警告。

## 四、已知限制

- 合同编号仍为三位流水（`HT-2026-001`），文档 4.2.4 目标态为四位，二期迁移时统一切换；
- 图形界面单文件 17 MB，主要体积来自静态编入的 SQLite 与中文字体渲染所需依赖，属正常；
- 本期不含支付申请、三级审批、红冲、结算、造价指标、RBAC —— 均为评审确认的延期项（见 `docs/口径主表.md` C 节）；
- **交付形态只有 GUI**，无命令行版本（R-25 决策）；
- **不做清单明细**（`ct_contract_item` 空表与 V3 分摊分支保留但无录入入口），也**不支持未分类暂存于草稿**（R-25 决策）；
- **付款打印只做数据预览，不输出 docx**：模板字段映射与 `PrintAdapter` 接口已就绪，待后期接入 Word 填充；
- 报表导出只覆盖 V3 / V4 两页，合同台账 / 拨款一览尚未接入 `ReportResult`。
